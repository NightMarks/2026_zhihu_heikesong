# 沙游心语三分钟演示流程

## 演示前检查

1. 打开 `/api/health`，确认 `ok` 为 `true`、`community` 为 `ready`。
2. 打开 `/api/capabilities`，确认 `oauthReady`、`aiReport`、`communityOnline` 均为 `true`。
3. 准备两个不同的知乎账号或两个独立浏览器会话，用于展示跨用户互动。

## 三分钟主流程

1. **0:00—0:20 登录门禁**：点击“登录知乎并开始旅程”，完成 OAuth 后自动返回游戏。
2. **0:20—0:55 内容探索**：从随机沙具进入真实知乎内容，说明站内互动由用户本人完成。
3. **0:55—1:35 沙盘创作**：把沙具从左侧库直接拖入沙盘，再演示移动、旋转、缩放、图层、撤销与重做。
4. **1:35—2:05 AI 报告**：完成布置后直接生成覆盖全部维度的非诊断式心理探索报告。
5. **2:05—2:30 发布**：公开发布作品，并导出带免责声明的沙盘图片。
6. **2:30—3:00 多人社区**：在另一个登录会话中刷新社区，展示新作品并点赞、收藏、评论；用“寻找共鸣伙伴”比较两座沙盘，发送并接受好友申请，再展示“仅好友可见”的作品。最后回到“我的沙盘”演示删除自己的已发布作品。

## 离线与故障说明

- 大模型不可用时报告回退到本地规则，但仍要求登录。
- 知乎内容接口不可用时展示错误提示，不伪造站内互动。
- 社区存储进入只读状态时停止发布和互动，避免覆盖损坏数据。
