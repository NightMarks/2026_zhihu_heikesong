# 沙游心语三分钟演示流程

## 演示前检查

1. 打开 `/api/health`，确认 `ok` 为 `true`、`community` 为 `ready`。
2. 打开 `/api/capabilities`，确认 `oauthReady`、`aiReport`、`communityOnline` 均为 `true`。
3. 准备两个不同的知乎账号或两个独立浏览器会话，用于展示跨用户互动。

## 三分钟主流程：每日热题

1. **0:00—0:20 登录门禁**：点击“登录知乎并开始旅程”，完成 OAuth 后自动返回游戏。
2. **0:20—0:40 进入热题**：点击与“沙盘报告”并列的“每日热题”，展示当天知乎热榜来源、心理主题、安全说明和四轮任务。
3. **0:40—1:25 做出选择**：进入沙盘完成“建立画面—发生变化—再次选择—回看过程”，演示增加、移除或移动沙具。说明系统记录的是操作差异，不是心理测试选项。
4. **1:25—1:55 选择镜像**：展示“事实证据 → 可能性”观察，现场确认一条、拒绝一条；强调拒绝内容不会进入画像，标签会随新记录变化且不是心理诊断。
5. **1:55—2:20 隐私与发布**：展示选择原型默认私密，主动开启某个标签的公开/匹配权限，再把挑战后的沙盘发布到原有社区。
6. **2:20—3:00 社区与好友**：在另一个登录会话刷新社区，查看对方主动公开的标签；分别演示关闭和开启标签匹配，查看独立匹配理由，再发送并接受好友申请。

## 自由创作备用流程

若现场更适合展示传统路径，可从随机沙具进入知乎内容，获得灵感并解锁沙具，再自由布置沙盘、生成 AI 心理探索报告、发布社区和匹配好友。每日热题不会覆盖或改变原有自由沙盘。

## 离线与故障说明

- 大模型不可用时报告回退到本地规则，但仍要求登录。
- 知乎热榜不可用、没有安全候选或命题生成失败时，每日热题使用内置安全命题；页面应明确显示来源状态，不伪造热榜内容。
- 知乎内容接口不可用时展示错误提示，不伪造站内互动。
- 社区存储进入只读状态时停止发布和互动，避免覆盖损坏数据。
